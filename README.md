# Password Generator Script with Tkinter

This script generates a password using the Python `Tkinter` library, and displays it in a window. The password is **masked** (shown with dots `•`), but the actual password can still be copied.

## Requirements
- Python 3.x (Ensure you have Python installed)
- Tkinter (Usually comes pre-installed with Python)

## Features
- **Generate a Random Password**: Based on user input (password length).
- **Password Masking**: The password is displayed as `•` characters in the GUI window.
- **Copyable**: The generated password is copyable to the clipboard with the click of a button.

## How to Use

1. **Install Python** (if you don’t have it already):  
   Download and install Python from [python.org](https://www.python.org/downloads/).

2. **Install Tkinter** (if necessary):  
   Tkinter is included by default in most Python installations, but if you don't have it, you can install it by running:
   ```bash
   pip install tk
````

3. **Run the Script**:

   * Save the provided Python code to a file, for example `password_generator.py`.
   * Open a terminal or command prompt and navigate to the folder where the script is saved.
   * Run the script by typing:

   ```bash
   python password_generator.py
   ```

4. **Input Password Length**:

   * Enter the desired **password length** in the input box.
   * Click **"Generate Password"** to display the masked password in the window.

5. **Copy the Password**:

   * After the password is displayed, click **"Copy Password"** to copy it to your clipboard.

## Example Interface

When the script runs, it will open a window that looks like this:

```
Enter password length: [Text input box]
[Generate Password Button]
[Masked Password Entry (••••••)]
[Copy Password Button]
```

Once you click **"Generate Password"**, the password will be displayed in a masked form (`• • • • •`), and you can click **"Copy Password"** to copy the actual password to your clipboard.
