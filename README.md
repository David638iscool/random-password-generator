# Password Generator Script with Tkinter

This repository contains a Python script that generates a random password and displays it in a Tkinter window. The password is **masked** with `•` characters in the UI but is still **copyable**.

## Features
- **Generate a Random Password** based on user-defined length.
- **Password Masking**: The password is displayed as `•` characters in the GUI window.
- **Copyable**: The generated password is copyable to the clipboard.

## Requirements
- **Python 3.x** (Ensure you have Python installed)
- **Tkinter** (Usually comes pre-installed with Python)

## How to Use

1. **Install Python** if you don’t already have it. Download and install it from [python.org](https://www.python.org/downloads/).
   
2. **Run the Script**:
   - Open a terminal/command prompt and navigate to the folder where the script is located.
   - Run the script using:
     ```bash
     python code.py
     ```

3. **Enter Desired Password Length**:
   - Input the desired password length in the provided text box.
   - Click **Generate Password** to display the masked password in the window.

4. **Copy the Password**:
   - Once the password is displayed, click **Copy Password** to copy it to your clipboard.
